一句话：泡在静水里解冻很慢，因为紧贴食物的那层水被冷却后就变成了保温层。
机理：静水会在食物表面形成一层接近冰点、几乎不流动的水膜，传热效率骤降。流动的水不断换掉这层冷膜，维持大温差，从而显著加快传热。这是边界层概念在厨房里的直接体现。
